# Editing Craft

## 1. Story Structure
- **Three-act shape:** setup → conflict/escalation → resolution. Short-form compresses this: hook → value/tension → payoff → loop/CTA.
- **Open loops:** raise a question early, answer it late; re-hook every 30–60 s in long-form (a tease, a stakes line, a visual change).
- **Information order:** show the viewer *why they care* before *how it works*.
- **Cut for the question, not the answer:** when two takes say the same thing, keep the one with more emotion and cleaner delivery.
- **Kill your darlings:** a gorgeous shot that doesn't move the story goes.

## 2. Hooks (first 1–3 s)
Patterns: *outcome-first* (show the end result), *bold claim*, *question/curiosity gap*, *pattern interrupt* (unexpected visual/sound), *in medias res* (start mid-action), *negative framing* ("Stop doing X"), *specific number* ("3 mistakes…"). Rules: no logo sting, no "Hey guys, welcome back" intro; first frame must be visually compelling; text hook readable in <1.5 s; audio hook (voice or hit) in the first 0.5 s. Always create 3–5 hook variants for A/B testing.

## 3. Pacing & Rhythm
- Cut rhythm follows content energy: calm = longer holds; tension = shortening shots; payoff = breathe.
- Avoid metronomic cutting; vary shot length with intent. Cut on musical downbeats for montage; off-beat for tension.
- Typical average shot length: short-form 1–3 s, YouTube talking head with B-roll 3–8 s, interview 4–12 s, trailer accelerates 6 s → 0.5 s.
- **Dead-air audit:** remove breaths > 0.4 s, filler words, restarts, "so basically". Keep ~3–6 frames of natural pause for comprehension (breathing room reads human).
- **Retention graph reading:** steep early drop = weak hook; drops at fixed spots = boring segment or ad-like pivot; spikes = replays (valuable moments → make clips); flat decline = pacing fine, topic fatigue.

## 4. Cutting Grammar
| Technique | Use |
|---|---|
| Hard cut | Default; invisible when motivated |
| J-cut (audio leads) / L-cut (audio trails) | Smooth dialogue, reaction shots, scene transitions |
| Match cut | Shape/motion/idea continuity between shots (also graphic match) |
| Action cut | Cut mid-movement (door open, turn, throw) — hides seams |
| Cutaway / B-roll | Cover jump cuts, illustrate claims, add context |
| Insert | Close detail to emphasize (hands, screens, props) |
| Smash cut | Abrupt energy/tonal contrast for comedy or shock |
| Jump cut | Social/vlog style; keep clearly different frame sizes (or punch-in) |
| Cross-dissolve | Time passage / softness; 12–24 frames; not a default |
| Whip/zoom/speed-ramp | Sparingly, on beat, motivated by motion |
| Montage | Rhythm + music; each shot ≥ 6–8 frames for legibility |
| Cross-cutting | Parallel action builds tension |

**Continuity rules:** 180° rule (keep screen direction), 30° rule (change angle ≥ 30° or size), match eyelines, match props/hands/lighting, don't cut between near-identical sizes without punch-in or B-roll.

**Dialogue editing:** cut on a breath or consonant, not mid-word; room-tone under every cut; overlap dialogue 2–6 frames in reaction scenes; cutaways to listener at emotional beats.

**Multicam:** sync by timecode/waveform, cut to the speaker with 3–6 frame anticipation, cut away for reactions, keep wide shot as safety.

## 5. B-roll & Visual Variety
- Plan B-roll per script beat: *illustrate, prove, contrast, relieve*.
- Vary shot sizes (wide/medium/close/macro), angles, motion; avoid > 8–10 s without a visual change in long-form talking head.
- Screen recordings: zoom/pan to the area of interest, highlight clicks, cut dead loading time.
- Stock/AI B-roll must be licensed and match the grade, frame rate, and tone.

## 6. Text, Graphics & Captions
- Captions boost mute-viewing retention: 1–2 lines, ≤ 42 chars/line, 4–7 words on screen, highlight key word, bold sans, outline/shadow, safe zones.
- Lower thirds: appear after the speaker settles (~1 s in), hold 4–5 s, ease in/out.
- Animations ease (ease-out in, ease-in out); durations 8–15 frames; no gratuitous effects.
- Brand consistency: ≤ 2 fonts, consistent colors, margins, motion language.

## 7. Transcript-Based Editing Workflow
1. Transcribe (Whisper/Descript/Resolve/Premiere text-based editing).
2. Mark selects in the transcript; delete tangents; reorder for narrative.
3. Cut silence/fillers, then listen for natural cadence — restore breaths.
4. Add B-roll per sentence; captions from the cleaned transcript.

## 8. Short-form Clip Extraction (from long content)
1. Find self-contained 20–60 s arcs with a strong first sentence and a payoff.
2. Re-open with the punchiest line (cold open) when the context isn't needed.
3. Reframe to 9:16 following the speaker; add captions, progress/loop cue, end on a loop-friendly beat or CTA.
4. Remove all "setup" filler; target ≥ 85% retention at 3 s, 50%+ through the end.

## 9. Common Editor Mistakes
Over-using transitions/effects; cutting too early on reaction beats; ignoring audio pops; inconsistent loudness across clips; mixed frame rates; leaving flash frames; baking captions too near edges; exporting with VFR; working on the only copy; no version notes; fixing in post what reshoots/pickups should solve.

## 10. Feedback Protocol (giving & receiving notes)
Timestamp every note; classify (Critical = story/clarity/legal, Important = pace/audio/color, Polish = taste); propose a fix, not only a problem; confirm the intended audience/goal before debating taste; track versions and approvals; lock picture before sending to color/mix.
